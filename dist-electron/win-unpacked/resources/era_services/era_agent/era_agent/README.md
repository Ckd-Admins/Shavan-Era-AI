# Era Agent for Windows

A local AI agent for Windows that executes simple, safe system commands.
It can be used two ways:

1. **Interactive CLI** (`main.py`) — type commands at a prompt.
2. **Local HTTP API** (`api_server.py`) — lets **Era**, an assistant built
   in Google AI Studio, call the same commands over HTTP.

Both use the exact same command registry, so behavior is identical
either way. No command requests administrator privileges or performs
any destructive action without confirmation — see the command list
below for details.

## Features

- Open Notepad
- Open Calculator
- Open File Explorer
- Open Google Chrome (if installed)
- Search for a file by name and open it in File Explorer
- Open WhatsApp with a message pre-filled for a contact
- Safely shut down or restart the computer (with a cancel window)
- Open the Camera app
- Open a specific browser (Chrome, Edge, Firefox, Brave)
- Open any app by name
- **Call any of the above from Era over a local HTTP API**

## Project structure


## Setup

1. Install Python 3.9 or newer from [python.org](https://www.python.org/downloads/)
   (make sure "Add Python to PATH" is checked during install).

2. Open this folder in VS Code (or any terminal).

3. (Recommended) Create a virtual environment:
   ```
   python -m venv venv
   venv\Scripts\activate
   ```

4. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
   This installs FastAPI, Uvicorn, and Pydantic, which the API server
   needs. The CLI and all commands still run on the standard library
   alone.

## Option 1: Running the interactive CLI

```
python main.py
```

You'll see a prompt like:

```
era>
```

Type any of the following and press Enter:

| Command              | Action                                     |
|-----------------------|---------------------------------------------|
| `open_notepad`        | Opens Notepad                              |
| `open_calculator`     | Opens Calculator                           |
| `open_file_explorer`  | Opens File Explorer                        |
| `open_chrome`         | Opens Google Chrome, if installed          |
| `search_file`         | Asks for a file name and finds/opens it    |
| `open_whatsapp`       | Asks for a contact and message, opens chat |
| `shutdown_pc`         | Safely shuts down (10s, cancellable)       |
| `restart_pc`          | Safely restarts (10s, cancellable)         |
| `cancel_shutdown`     | Cancels a pending shutdown/restart         |
| `open_camera`         | Opens the Camera app                       |
| `open_browser`        | Asks which browser, then opens it          |
| `open_app`            | Asks for an app name, then opens it        |
| `help`                | Lists all available commands               |
| `exit` or `quit`      | Closes the agent                           |

Each command prints a result line, for example:

```
era> open_notepad
[SUCCESS] open_notepad: Notepad opened successfully.

era> open_chrome
[FAILURE] open_chrome: Google Chrome was not found on this system. Make sure it is installed in the default location.
```

## Option 2: Running the API server (for app integration)

The API server (`api_server.py`) exposes Era Agent over HTTP, allowing external applications (Web apps, Mobile apps, Desktop apps, or AI assistants like Era) to trigger any system command with parameters.

### Start the server

You can start the server in any of the following ways:

1. **Double-click launcher (Windows)**:
   Double-click `run_api.bat` in File Explorer.

2. **Python directly**:
   ```cmd
   python api_server.py
   ```

3. **Uvicorn**:
   ```cmd
   uvicorn api_server:app --reload --port 8000
   ```

The server runs on `http://127.0.0.1:8000`. Leave the window open while your app is connected.

### API Endpoints

| Method | Path        | Purpose                                                         |
|--------|-------------|-----------------------------------------------------------------|
| GET    | `/status`   | Health check — confirms agent is running & reports version      |
| GET    | `/commands` | Returns all available commands, descriptions & parameter schemas|
| POST   | `/execute`  | Executes a command by name with optional parameters             |
| GET    | `/docs`     | Interactive Swagger UI (auto-generated by FastAPI)             |

### How to Connect Your App to Era Agent

#### 1. JavaScript / Web App (Fetch API)

```javascript
// Execute a command with parameters (e.g. open Spotify or VS Code)
async function runEraCommand(commandName, params = {}) {
  const response = await fetch("http://127.0.0.1:8000/execute", {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({
      command: commandName,
      params: params
    })
  });
  const result = await response.json();
  console.log(result); // { success: true, message: "'spotify' opened successfully." }
  return result;
}

// Example usage:
runEraCommand("open_app", { app_name: "spotify" });
runEraCommand("open_notepad");
runEraCommand("search_file", { file_name: "document.pdf" });
runEraCommand("open_whatsapp", { phone: "+1234567890", message: "Hello from my app!" });
```

#### 2. Python Client Example

```python
import requests

API_URL = "http://127.0.0.1:8000/execute"

# Launch Notepad
res = requests.post(API_URL, json={"command": "open_notepad"})
print(res.json())

# Open a specific application
res = requests.post(API_URL, json={
    "command": "open_app",
    "params": {"app_name": "vscode"}
})
print(res.json())
```

#### 3. Testing with cURL

```bash
# Check API Status
curl http://127.0.0.1:8000/status

# List commands and parameter schemas
curl http://127.0.0.1:8000/commands

# Open Notepad
curl -X POST http://127.0.0.1:8000/execute \
  -H "Content-Type: application/json" \
  -d "{\"command\": \"open_notepad\"}"

# Open any application with params
curl -X POST http://127.0.0.1:8000/execute \
  -H "Content-Type: application/json" \
  -d "{\"command\": \"open_app\", \"params\": {\"app_name\": \"calc\"}}"
```

#### 4. Testing with Postman

1. Request Method: `POST`
2. Request URL: `http://127.0.0.1:8000/execute`
3. Headers: `Content-Type: application/json`
4. Body (`raw` -> `JSON`):
   ```json
   {
     "command": "open_app",
     "params": {
       "app_name": "notepad"
     }
   }
   ```
5. Click **Send**.

### Error Handling & Responses

- Successful command execution returns HTTP `200`:
  ```json
  { "success": true, "message": "Notepad opened successfully." }
  ```
- Command failure returns HTTP `200` with `success: false`:
  ```json
  { "success": false, "message": "Could not find or open 'unknown_app'." }
  ```
- Validation error (missing required `command` field) returns HTTP `422`.
- Internal server exception returns HTTP `500` with error details.

## Adding a new command

The project is built so new commands don't require touching `main.py` or `api_server.py`:

1. Open `commands/system_commands.py`.
2. Write a function that returns a `CommandResult` and register it with `CommandParam` metadata:

   ```python
   from .registry import CommandResult, CommandParam, registry

   @registry.register(
       "open_paint",
       "Opens Microsoft Paint",
       params=[]
   )
   def open_paint() -> CommandResult:
       import subprocess
       try:
           subprocess.Popen(["mspaint.exe"])
           return CommandResult(True, "Paint opened successfully.")
       except OSError as exc:
           return CommandResult(False, f"Failed to open Paint: {exc}")
   ```

That's it — the new command automatically appears in `help`, CLI `era>` prompt, `GET /commands`, and can be triggered via `POST /execute`.
